# ROI检测区域配置与坐标归一化

## 功能概述

✅ **过滤ROI外的物体**：只检测和发送ROI矩形区域内的物体  
✅ **坐标归一化**：将物体坐标从像素坐标转换为0-1归一化坐标  
✅ **自动分辨率适配**：ROI配置基于320x256标定，自动缩放到实际摄像头分辨率  
✅ **实时可视化**：画面显示蓝色ROI框和归一化坐标

## 分辨率自动适配

**标定分辨率**：320x256（calibration/calibrate_roi_serial.py使用的分辨率）  
**运行分辨率**：由模型输入尺寸决定（main.py自动检测）  
**自动缩放**：程序会自动将ROI坐标从320x256缩放到实际分辨率

**示例**：
- 标定时：320x256，ROI为 (80, 50, 160, 155)
- 运行时：如果模型使用320x256，ROI保持不变 (80, 50, 160, 155)
- 运行时：如果模型使用640x480，ROI自动缩放为 (160, 94, 320, 291)

## 当前配置

```json
{
  "x": 80,
  "y": 50,
  "width": 160,
  "height": 155
}
```

**配置说明**：这是基于320x256的坐标，实际运行时会自动缩放

## 串口输出格式

```
类别ID,归一化X,归一化Y\r\n
```

**示例**：
```
0,0.5000,0.5000    # 类别0，位于ROI中心
1,0.1562,0.1613    # 类别1，位于ROI左上区域
2,0.8438,0.8387    # 类别2，位于ROI右下区域
```

## 坐标映射示例

| 物体位置 | 像素坐标 | 归一化坐标 | 说明 |
|---------|---------|-----------|------|
| ROI左上角 | (150, 100) | (0.0000, 0.0000) | 坐标原点 |
| ROI右下角 | (470, 410) | (1.0000, 1.0000) | 最大值 |
| ROI中心 | (310, 255) | (0.5000, 0.5000) | 中心点 |
| ROI外 | (100, 200) | - | 被过滤，不发送 |

## 修改ROI区域

### 方法1：重新标定（推荐）
```bash
python calibration/calibrate_roi_serial.py
```
通过串口命令调整矩形，按Q保存。标定工具使用640x480分辨率，保存的配置会在main.py中自动缩放。

### 方法2：直接编辑
修改 `/root/roi_config.json` 或本地 `roi_config.json`。
**注意**：配置文件中的坐标必须基于640x480分辨率，程序会自动缩放到实际运行分辨率。

### 方法3：删除配置
```bash
rm /root/roi_config.json
```
删除后将恢复全视野检测（不过滤，不归一化）

## 使用优势

1. **分辨率无关**：标定一次，适配任何模型分辨率
2. **下游设备简化**：接收方无需知道摄像头分辨率和ROI位置
3. **坐标统一**：所有坐标都在0-1范围，便于跨平台处理
4. **灵活调整**：修改ROI不影响下游代码逻辑
5. **视觉反馈**：画面上显示蓝色ROI框和归一化坐标便于调试

## 技术细节

程序启动时会显示：
```
摄像头分辨率: 320x224
ROI缩放比例: x=0.500, y=0.467
缩放后ROI: (75, 46) 160x144
```

这表示：
- 实际运行分辨率是320x224
- ROI坐标从640x480缩放到320x224
- 缩放后的ROI用于检测过滤和归一化计算
