# 八色 LAB 实物标定

从桌面启动“颜色标定”，不要与“几何体检测”同时运行。标定应用沿用正式程序的 320×256 RGB 相机设置，不启动 YOLO，也不使用本工程 UART。顶部选择红、橙、黄、绿、蓝、紫、黑、白；点击画面中物料**内部**采样，每次取原始帧的 9×9 像素并显示 LAB 中位数、像素离散度和颜色预览。每色至少四次：正面、倾斜、移位和较暗表面。避开反光点、背景、边缘和界面按钮。底部可撤销最后一个样本、重采当前颜色、保存和退出。

先采齐红、黄、蓝、白各四次，才允许保存。橙、绿、黑可分别补齐后启用；暂无紫色实物时不采紫色。某个新增颜色只采到 1–3 次时保存会失败，旧文件继续有效；退出未保存同样不会改动旧文件。保存通过同目录临时文件、同步写盘及原子替换完成，文件在 `/root/lab_colors.json`。每次标定数据独立保存为一个样本，附像素离散度和用于估测提示的允许距离；运行时不会合并成宽阈值。

标定后退出到桌面再启动“几何体检测”。主页应显示 `LAB N/8`；不足八色会提示缺色可能误判。逐件把实物放入视野，检查正面、倾斜、阴影三种情况，并对照 MCU 模拟器收到的颜色编号：红01、橙02、黄03、绿04、蓝05、紫06、黑07、白08。部分标定期间，未启用的颜色可能被估测成已启用颜色，不能把其编号当作已验证。记录颜色估测数与 `SCAN_TIMING` 的 `color_ms`，观察快照首字节间隔、异常及重启日志。

回退：在正式应用的 `config.py` 设 `COLOR_MODE = "hsv"` 并从桌面重启。缺失、损坏或样本不足的 LAB 文件也自动回退 HSV，启动日志会说明原因。部署前备份旧应用和旧 `/root/lab_colors.json`；恢复原文件后重启可恢复原标定。LAB 校正只针对判色，不代表已解决整机卡死。
