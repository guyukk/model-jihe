# ROI（感兴趣区域）标定使用说明

## 概述

现在主程序支持只检测视野中特定矩形区域内的物体。只有物体中心坐标落在ROI矩形范围内的检测结果才会被保留，并且坐标会被归一化到0-1范围。

## 当前ROI配置

```json
{
  "x": 150,
  "y": 100,
  "width": 320,
  "height": 310
}
```

这意味着只有物体中心在 (150, 100) 到 (470, 410) 范围内才会被检测和发送。

## 标定流程

### 1. 运行标定工具

将 `calibration/calibrate_roi_serial.py` 上传到MaixCAM2设备，然后运行：

```bash
python calibration/calibrate_roi_serial.py
```

### 2. 通过串口调整ROI

程序启动后，屏幕上会显示一个绿色矩形框和中心十字线。通过串口发送以下命令来调整：

| 命令 | 功能 |
|------|------|
| `U`  | 向上移动矩形 |
| `D`  | 向下移动矩形 |
| `L`  | 向左移动矩形 |
| `R`  | 向右移动矩形 |
| `W`  | 增加矩形高度 |
| `S`  | 减少矩形高度 |
| `A`  | 减少矩形宽度 |
| `E`  | 增加矩形宽度 |
| `Z`  | 重置为全屏 |
| `Q`  | 保存并退出 |

**发送示例（使用串口助手或Python）：**

```python
import serial

ser = serial.Serial('COM3', 115200)  # 根据实际端口修改
ser.write(b'U')  # 向上移动
ser.write(b'E')  # 增加宽度
ser.write(b'Q')  # 保存退出
ser.close()
```

### 3. 保存配置

调整满意后发送 `Q` 命令，程序会将ROI配置保存到 `/root/roi_config.json`

配置文件格式：
```json
{
  "x": 160,
  "y": 120,
  "width": 320,
  "height": 240
}
```

## 使用ROI配置

主程序 `main.py` 会自动加载 `/root/roi_config.json` 配置：

- **如果配置文件存在**：只检测ROI矩形内的物体，屏幕上会显示蓝色矩形框标识ROI区域
- **如果配置文件不存在**：检测整个视野的物体（原有行为）

## 修改或删除ROI配置

### 方法1：重新标定
重新运行 `calibration/calibrate_roi_serial.py` 进行标定

### 方法2：手动编辑
直接修改 `/root/roi_config.json` 文件中的坐标和尺寸

### 方法3：删除配置
删除 `/root/roi_config.json` 文件，程序将恢复检测全视野

```bash
rm /root/roi_config.json
```

## 工作原理

1. 主程序在检测物体后，计算每个检测框的中心坐标 `(center_x, center_y)`
2. 检查中心坐标是否在ROI矩形内：
   - `roi["x"] <= center_x <= roi["x"] + roi["width"]`
   - `roi["y"] <= center_y <= roi["y"] + roi["height"]`
3. **过滤ROI外的物体**：不在ROI内的检测结果会被丢弃
4. **坐标归一化**：ROI内的物体坐标会被归一化到0-1范围
   - `norm_x = (center_x - roi["x"]) / roi["width"]`
   - `norm_y = (center_y - roi["y"]) / roi["height"]`
   - ROI左上角对应 (0, 0)，右下角对应 (1, 1)
5. 只有满足条件的检测结果才会被显示、记录和通过串口发送

## 串口输出格式

归一化后，串口发送的数据格式为：

```
类别ID,归一化X,归一化Y\r\n
```

**示例：**
```
0,0.5000,0.5000
1,0.2345,0.7890
```

- 第一列：物体类别ID（整数）
- 第二列：归一化X坐标（0.0-1.0浮点数，保留4位小数）
- 第三列：归一化Y坐标（0.0-1.0浮点数，保留4位小数）

**坐标含义：**
- `(0.0, 0.0)` = ROI左上角
- `(1.0, 1.0)` = ROI右下角
- `(0.5, 0.5)` = ROI中心点

这样下游设备无需知道实际像素坐标，只需要知道物体在ROI中的相对位置。

## 注意事项

- ROI坐标基于摄像头分辨率（640x480）
- 标定时确保矩形不要超出画面边界
- 蓝色框（ROI）和红色框（检测结果）会同时显示，方便确认检测区域
- ROI配置持久化保存，重启后仍然有效
